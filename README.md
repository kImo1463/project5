**Overview**

This project is a social networking platform designed to replicate key features of Twitter (X). Users can share updates, engage with others through likes and retweets, and build their network by following or unfollowing other users. The platform offers an interactive and real-time experience, making it easy for users to connect and communicate.

**Features**

User Authentication: Register, login, logout, and password recovery.

Post Updates: Users can create, edit, and delete posts.

Like & Retweet: Engage with posts through likes and shares.

Follow System: Follow or unfollow users and personalize your feed.

Real-time Updates: Live feed updates powered by WebSockets or polling.

Profile Management: Update profile details, including profile pictures and bios.

Comment System: Users can reply to posts and engage in discussions.

Notifications: Get alerts for likes, retweets, follows, and comments.

**Tech Stack**

Backend: Django (Python)

Frontend: HTML, CSS, JavaScript (Optional: React or Vue.js)

Database: SQLite

Authentication: Django Authentication System

Real-time Features: Django Channels for WebSockets
